# D0001. Agents work here under the agent kit's guardrails and the ship flow ({{date}})

**Status:** Active

**Chosen:**
- Claude Code reads `AGENTS.md` (through `CLAUDE.md`) for the commands and rules.
- `.claude/settings.json` and its guard hook hold the guardrails; `.claude/agent-kit.json` lists any baseline rule removed on purpose. <!-- docs-check: elsewhere -->
- Work is tracked as foreman tasks; `foreman.json` lists the paths whose changes need a person's approval.
- One file per decision in this folder, numbered by foreman's `reserve_number`.

**Why:** Agents write most of the code, so the rules have to be written down where they read them and enforced by tools, not by memory.

**Revisit if:** the project stops using coding agents, or moves to a tool that doesn't read these files.
